# 75 Hard Tracker

A mobile-first, local-first PWA for tracking a 75-day challenge.

## V1
- 75-day calendar and current-day dashboard
- Official 7 daily requirements
- 3.785 L water target
- Reading progress
- Weight and notes
- Streak and completion tracking
- Offline/PWA support
- LocalStorage persistence

## Run
Open `index.html` locally or deploy the repository with GitHub Pages/Netlify. For iPhone installation, open the deployed HTTPS URL in Safari → Share → Add to Home Screen.
